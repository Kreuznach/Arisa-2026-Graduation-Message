## 5. 아직 확인하지 못한 것 (솔직하게)

- **진짜 Supabase 로 처음부터 끝까지** — 아리사 SQL 을 아직 실행하지 않아서 못 했어요. 가짜 DB 는 진짜 SQL 파일을 그대로 적용한 PGlite(Postgres)라서 DB 로직은 같이 검증됐지만, PostgREST 와 Supabase Auth 의 실제 응답은 배포 후 [배포 가이드 6번](DEPLOYMENT.md) 순서로 한 번 확인해야 해요.
- **실제 기기** (iPhone Safari, 안드로이드, 태블릿) — 브라우저 창 크기로만 확인했어요. 전체화면 버튼과 화면 꺼짐 방지는 기기마다 달라요.
- **QR 을 진짜 카메라로 찍어 보기** — QR 은 검증된 라이브러리(MIT)로 만들고 위치 패턴을 검사했지만, 현장에서 직접 찍어 보세요.
- **저사양 폰의 부드러움** — 개수와 효과를 가볍게 만들었지만 실측은 못 했어요.
