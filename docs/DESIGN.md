# 디자인 안내 — 핑크 테마와 "Enchanted → Disenchanted"

> 편지 경험은 모카와 같게, 공간의 색감과 감정적인 배경은 아리사만의 것으로.
> 모카의 마법은 라벤더빛 추억이고, 아리사의 마법은 서서히 풀려가는 핑크빛이에요.

## 1. 색깔 (`public/assets/arisa-theme.css` 맨 위)

모든 색은 `.arisa-theme` 안의 변수 하나씩으로만 정해요. 색을 바꾸고 싶으면 이 부분만 고치면 돼요.

| 변수 | 색 | 어디에 쓰나요 |
|---|---|---|
| `--arisa-bg-1` / `-2` / `-3` | `#FFF4F7` / `#F5C9D9` / `#E9A9C4` | 배경 그라데이션 (165도) |
| `--arisa-pink-light` | `#FBE0EA` | 연한 포인트 |
| `--arisa-pink` | `#D979A0` | 점·장식 |
| `--arisa-rose` | `#AD3E6C` | 강조 글자, 선택된 버튼, 하트 봉인 |
| `--arisa-rose-dark` | `#873253` | 관리자 미리보기 안내줄 |
| `--arisa-text` / `--arisa-text-sub` | `#4E303D` / `#775763` | 본문 / 보조 글자 |
| `--arisa-paper` / `--arisa-paper-line` | `#FFFDF9` / `#F4DCE4` | 편지지(따뜻한 아이보리) / 가로줄 |
| `--arisa-card-bg` / `-border` | 흰색 82% / 흰색 85% | 반투명 카드 |
| `--arisa-glow` / `--arisa-shadow` | 핑크 30% / 로즈 14% | 후광 / 그림자 |

- 주요 버튼: `#AD3E6C → #C9638C` 그라데이션 + 흰 글자.
  글자가 놓이는 가운데까지는 진한 색을 유지해서 **대비 4.5:1 이상**을 지켜요. (자동 테스트가 계산해요)
- 편지지는 핑크를 칠하지 않고 **아이보리**로 남겨 두었어요.
- 무지개색, 보라색 중심 배경, 강한 네온핑크는 쓰지 않아요. 모카의 라벤더 색이 코드에 남아 있지 않은지도 테스트가 검사해요.

## 2. 배경 (끝까지 핑크)

겹겹의 `radial-gradient` 만 써요. 이미지, 캔버스, `blur` 는 쓰지 않아요.

| 층 | 모습 |
|---|---|
| 위쪽 광원 | 화면 위에서 내려오는 옅은 핑크빛 |
| 가운데 조명 | 부드러운 크림색 |
| 가장자리 음영 | 아래·양옆의 흐릿한 로즈색 |
| 느린 핑크빛 | 54초 동안 천천히 움직이는 반투명 핑크 (`arisa-stage__drift`) |
| 숨 쉬는 빛 | 16초 동안 아주 천천히 밝아졌다 어두워지는 위쪽 빛 |

## 3. 배경 이모지의 한 살이 (5단계)

각 이모지는 12~22초 동안 이 다섯 단계를 반복해요.

| 단계 | 시간(한 바퀴 기준) | 일어나는 일 |
|---|---|---|
| 1. **Enchant** 나타남 | 0 ~ 16% | 투명 → 또렷, 조금 커지고, 핑크 후광이 켜져요 |
| 2. **Shimmer** 반짝임 | 16 ~ 42% | 좌우로 살랑, 미세하게 회전, 밝기가 오르내리고, 작은 별(✧)이 반짝여요 |
| 3. **Disenchant** 마법이 풀림 | 42 ~ 72% | 후광이 줄고, 색이 연해지고, 밝기가 원래대로, 조금 작아져요 |
| 4. **Dissolve** 흩어짐 | 72 ~ 100% | 천천히 투명해지고, 작은 입자가 위·아래로 흩어져요 |
| 5. **Reappear** 다시 나타남 | 다음 바퀴 | **다른 자리, 같은 그룹의 다른 이모지**로 다시 시작해요 |

- 모든 이모지는 **서로 다른 주기와 시작 시점**을 가져서, 한꺼번에 사라지거나 한꺼번에 나타나는 일이 없어요.
- 종류 (기획서 그대로)
  - 1차 *Enchanted Pink*: 💖 💗 💞 🩷 💕 🎀 🌸 ✨
  - 2차 *Disenchantment*: 🫧 🥀 🥹 💔 (전체의 약 25%)
  - ✧ 와 빛 입자는 이모지가 아니라 **CSS 도형**이에요.
- 개수: 모바일 12개, 데스크톱 22개
- 위치: 화면 **양쪽 가장자리**. 가운데 글 쓰는 곳 쪽으로는 들어오지 않아요.
- 자리와 모양은 **고정된 씨앗(seed)** 으로 정해서, 화면을 다시 그려도 같은 배치가 돼요.

### 왜 이모지 색을 직접 안 바꾸나요?

컬러 이모지는 기기마다(iPhone, Android, Windows) 그림이 달라서 CSS `color` 로는 핑크로 바꿀 수 없어요.
그래서 이렇게 했어요.

- 이모지 본체는 그대로 쓰고
- **핑크 후광은 따로 겹친 층**(`.ae__halo`)으로 만들고
- 마법이 풀리는 느낌은 `opacity`, `filter`, `scale` 로 표현했어요.

### 네 겹 구조 (움직임이 서로 부딪히지 않게)

```text
.ae          바깥  : 위치와 느린 이동 (fall / sway / rise / float)  ← transform 만
 ├ .ae__life   안쪽  : 나타남·사라짐 (opacity, scale, 채도)           ← 기획서의 arisaDisenchant
 │   ├ .ae__halo   핑크 후광 (켜졌다 줄어듦)
 │   └ .ae__glyph  이모지 글자 (반짝임: 좌우 흔들림, 회전, 밝기)
 └ .ae__p      반짝이는 별 2개, 흩어지는 입자 2개 (CSS 도형)
```

## 4. 성능과 접근성

| 항목 | 방법 |
|---|---|
| 가볍게 | 애니메이션은 `transform`/`opacity` 위주, 자바스크립트는 배치만 하고 프레임마다 돌지 않아요. 편지를 쓰는 동안 입력이나 스크롤에 끼어들지 않아요 |
| 가리지 않게 | 이모지 층은 카드 **뒤**(`z-index`)에 있고 `pointer-events: none` 이라 클릭도 못 막아요 |
| 접근성 트리에서 제외 | 장식 층에 `aria-hidden="true"` |
| 선택 불가 | `user-select: none` |
| 움직임 끄기 | 화면의 **움직임 끄기** 버튼, 또는 기기의 "동작 줄이기" 설정. 켜기를 누르면 기기 설정보다 우선해요 |
| 멈춘 모습도 예쁘게 | 움직임이 꺼져도 핑크 배경과 정지된 이모지(반투명), 후광이 그대로 남아요 |
| 안 보이는 탭 | 탭이 가려지면 모든 애니메이션을 일시정지 |
| 긴 편지를 읽을 때 | 배경 이모지를 30% 밝기로 낮춰서 글이 잘 보여요 |

## 5. 편지 경험은 그대로 (바꾸지 않은 것)

기존 모카 편지 화면의 **구조와 타이밍**을 그대로 가져왔고, 색과 문구만 바꿨어요.

| 부분 | 그대로인 것 | 바뀐 것 |
|---|---|---|
| 편지 쓰기 | 편지지 모양, 30px 가로줄, 입력 영역 크기(8줄 이상), 줄바꿈 처리, 버튼 위치, 제출 성공 화면, 안내 문구 자리 | 색(핑크), 이름(모카 → 아리사) |
| 봉투 열기 | 선택 → 하트 봉인 사라짐(0.3초) → 플랩 열림(0.5초, 0.35초 뒤 시작) → 편지지 올라옴(0.55초, 0.85초 뒤 시작) → 원문. 전체 **약 1.4초** | 봉투는 핑크, 하트 봉인은 로즈 |
| 열람 | 긴 편지 스크롤, 이전/다음, 목록으로, `Esc`, 연출 건너뛰기, 모바일 전체 화면 열람 | 편지지는 아이보리 그대로 |
| 목록 | 데스크톱 2열 / 모바일 1열, 필터, 정렬, 페이지 | 색 |

봉투 열기 키프레임(`lb-seal`, `lb-flap`, `lb-paper`)은 배경 이모지 코드와 **완전히 분리**되어 있어서
이모지 연출이 봉투 연출에 영향을 주지 않아요. (자동 테스트가 값과 길이를 검사해요)

## 6. 색을 바꾸고 싶을 때

1. `public/assets/arisa-theme.css` 맨 위의 `.arisa-theme { … }` 변수를 고쳐요.
2. 봉투 색은 `letters.css`(`mini-envelope__*`)와 `letterbox.css`(`lb-mini-*`, `lb-stage-*`)에 있어요.
3. `npm test` 의 "색 토큰", "색 대비" 테스트가 기획서 색과 달라지면 알려 줘요. 일부러 바꾼 거라면 테스트의 기준값도 같이 바꿔 주세요.
